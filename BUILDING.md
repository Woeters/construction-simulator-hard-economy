# Building Hard Economy 0.1.0-beta

These instructions recreate the ready-to-use Hard Economy patcher ZIP from the
public source in this repository. They do not build Construction Simulator and
do not require any Construction Simulator game file.

## Requirements

- Windows 10 or Windows 11
- Windows PowerShell 5.1
- The Windows archive from the
  [UABEA v7 release](https://github.com/nesrak1/UABEA/releases/tag/v7),
  named `uabea-windows.zip`

Expected SHA-256 for `uabea-windows.zip`:

```text
6C5A7FB80B7A7C6433D69A6D2FD37FA4D42E97A9CA01B7CCAF4412D5F3C9AEF6
```

The build uses five MIT-licensed runtime files from that archive:

## Build steps

1. Download or clone this repository.
2. Download `uabea-windows.zip` from the UABEA v7 release linked above.
3. Open Windows PowerShell in the repository directory.
4. Run:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\tools\Build-Release.ps1 -UabeaArchive "C:\Path\To\uabea-windows.zip"
```

The finished archive is created at:

```text
build\artifacts\Hard_Economy_0.1.0-beta_Patcher.zip
```

## What the build script does

1. Verifies the exact SHA-256 of the UABEA v7 Windows archive.
2. Copies the public Hard Economy PowerShell and launcher sources.
3. Extracts only the five required third-party runtime files.
4. Verifies every extracted third-party file by SHA-256.
5. Generates `GameAssembly.hmpatch` from the readable byte ranges in
   `patches/GameAssembly.patch.json`.
6. Verifies that the generated patch payload has SHA-256:

```text
5FE624F34D07BCC2DB4B59E54C33C727F4214A9C1F4545988AEE65562864707E
```

7. Packages the resulting folder as the distributable ZIP.

ZIP hashes can differ because ZIP metadata can contain different timestamps.
The build instead verifies the hashes of all security-sensitive inputs and the
generated binary patch payload.

## Patch sources

The two modified game files are produced locally when the end user runs the
patcher:

- `GameAssembly.dll` is patched from the explicit byte ranges stored in
  `patches/GameAssembly.patch.json`.
- The economy asset bundle is regenerated by the readable field changes in
  `src/Apply-HardModeEconomyBundle.ps1`.

The patcher accepts only the supported original hashes and validates the
resulting modified hashes before installing either file.

No original or modified Construction Simulator file is stored in this
repository or in the release archive.
